A web-based management system created to help a mobile phone
distribution company manage inventory and warranty-related operations.

**Main features include:**

- 📦 Incoming shipments and Goods Received Notes (GRN)
- 📊 Opening stock and available stock management
- 🛒 Sales and sales returns
- 🔧 Warranty returns and repairs
- 🔄 Warranty replacements
- 📋 Shipment-wise stock tracking
- 📈 Inventory and business management

**Project Type:** Personal / Development Project

### 📚 Web Based Library Management System

A group software engineering project developed at SLIIT to

**Main features include:**

- 👤 Member registration and login
- 📚 Book and catalog management
- 📦 Inventory management
- 🔄 Borrowing and returns
- 💰 Fine management
- 🔎 Online book search
- 📌 Book reservations
- 📊 Reports and analytics
- 🔐 Password reset and profile management

**Project Type:** University Group Project
